# Recommendation Service — MVP для Банка «Стар»

**MVP сервиса персональных рекомендаций банковских продуктов** на основе анализа транзакционной активности клиентов. Проект построен на базе Spring Boot и использует высокопроизводительные SQL-запросы через `JdbcTemplate` для работы со встроенной базой данных H2.

## 🚀 Стек технологий
* **Java 17**
* **Spring Boot 3.x** (Spring Web, Spring JDBC)
* **H2 Database** (Встроенная файловая БД, режим `READ_ONLY`)
* **Паттерны проектирования:** «Стратегия» (Strategy) для динамического добавления бизнес-правил.

## ⚙️ Конфигурация подключения к БД
Подключение к существующей базе данных транзакций настраивается в файле `src/main/resources/application.properties`:
```properties
spring.datasource.url=jdbc:h2:file:./transaction;ACCESS_MODE_DATA=r
spring.datasource.driver-class-name=org.h2.Driver
spring.jpa.hibernate.ddl-auto=none
```

## 🛠️ Архитектура и Расширяемость
Бизнес-логика фильтрации продуктов вынесена в изолированные компоненты с общей абстракцией:
1. **`RecommendationRuleSet`** — единый интерфейс с методом `Optional<RecommendationDto> check(UUID userId)`.
2. **Динамический сбор правил** — `RecommendationService` автоматически внедряет все реализации интерфейса через `List<RecommendationRuleSet>` (IoC-контейнер Spring), что позволяет добавлять новые банковские продукты без изменения существующего сервисного слоя.
3. **Оптимизация запросов** — `TransactionRepository` выполняет параметризованные `JOIN` запросы, минимизируя нагрузку на память приложения и базу данных.

## 🚦 Эндпоинты API
### Получение рекомендаций по ID пользователя
* **URL:** `/recommendation/{user_id}`
* **Метод:** `GET`
* **Формат успешного ответа (200 OK):**
```json
{
  "user_id": "cd515076-5d8a-44be-930e-8d4fcb79f42d",
  "recommendations": [
    {
      "id": "147f6a0f-3b91-413b-ab99-87f081d60d5a",
      "name": "Invest 500",
      "text": "Откройте свой путь к успеху с индивидуальным инвестиционным счетом (ИИС)..."
    }
  ]
}
```
